# 🚀 Apna GitHub Clone

A GitHub-inspired full-stack web application built using the **MERN Stack**, featuring user authentication, repository management, issue tracking, and a custom-built version control system with AWS S3 integration.

## ✨ Features

- 🔐 User Authentication and Authorization
- 📁 Create and Manage Repositories
- 🐛 Issue Creation and Tracking
- 🔄 Custom Version Control System
- ☁️ AWS S3 Cloud Storage Integration
- 📦 Commit, Push, Pull, and Revert Operations
- ⚡ Real-time Communication using Socket.IO

## 🛠️ Tech Stack

- **Frontend:** React.js, JavaScript, CSS, Vite
- **Backend:** Node.js, Express.js
- **Database:** MongoDB, Mongoose
- **Authentication:** JWT, bcrypt.js
- **Cloud Storage:** AWS S3
- **Real-time:** Socket.IO

## ⚙️ Installation

**1. Clone the repository**
```bash
git clone https://github.com/YOUR-USERNAME/APNA-GITHUB-CLONE.git
cd APNA-GITHUB-CLONE
```

**2. Install backend dependencies**
```bash
cd backend
npm install
```

**3. Configure environment variables**

Create a `.env` file and add your MongoDB, JWT, and AWS credentials.

**4. Start the backend**
```bash
npm start
```

**5. Start the frontend**

Open another terminal:
```bash
cd frontend
npm install
npm run dev
```
